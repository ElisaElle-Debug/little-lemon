# Little Lemon Front-End Developer Capstone

This project is the final capstone project for the Meta Front-End Developer Professional Certificate.

The application is a responsive React web app for the fictional Little Lemon restaurant. It includes a table reservation system that allows users to select a date, choose an available reservation time, enter the number of guests, choose an occasion, and submit a booking.

## Features

- Responsive Little Lemon homepage
- Semantic HTML structure
- React components
- React Router navigation
- Table reservation form
- Controlled form inputs using React state
- Available reservation times loaded through the booking API
- Booking submission through the API
- Booking confirmation page
- HTML5 and React form validation
- Accessibility improvements
- Responsive CSS layout
- Unit tests using React Testing Library and Jest
